# NEON DASH

Неоновый кибер-платформер на время с призраком лучшего забега. Android 7.0+.

## Скачать

Готовый APK: [neon-dash.apk](https://github.com/odisodisseyt-design/neon-dash/releases/download/v1.0.0/neon-dash.apk) из релиза [v1.0.0](https://github.com/odisodisseyt-design/neon-dash/releases/tag/v1.0.0).

Установка: скачайте файл на телефон и откройте его. Если Android блокирует установку, разрешите установку из неизвестных источников для файлового менеджера.

## Управление

- **Телефон:** сенсорные кнопки внизу экрана (можно жать две одновременно).
- **ПК:** `A/D` или `←/→` — бег, `Пробел` — прыжок (удержание выше), `Esc` — пауза, `R` — рестарт, `M` — музыка.

## Суть игры

Один уровень на время. Смерть даёт штраф +1.5 с и возвращает к чекпоинту. Призрак повторяет ваш лучший забег. Рекорд и топ-5 результатов сохраняются локально на устройстве.

APK подписан стандартным Android debug-ключом; подпись проверена через `apksigner` (схемы v2/v3).
